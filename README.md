# Hiya
If you're confused why, or better yet how, this is a 3D game and/or why I chose this for project, I thought I would have some extra fun by seeing how far Java Swing was able to handle such. Obviously I could've used the JavaFX package to do 3D and that would've saved me a solid 12 hours, but this was honestly a-lot more fun to test the limits of.

I've listed in [`src\GameEnvironment.java`](src\GameEnvironment.java) a repository I used for a-lot of my understanding and implementation, and also throughout my sources included the articles I read that really helped with logic especially with 3D projection with the camera. Obviously I wrote over pretty much all of it for the final product, but it was a huge part of the staging phase for my work.

I originally had it so that the sphere would actually be treated as an object that moved, but then I realized that I could just have the sphere be a 2d graphic and have it so the world moves around it. There's obviously a ton of bugs with this method, but definitely saved me a ton of time.

I listed in the [`src\main.java`](src\main.java) the images I used in [`resources`](resources), one's from Deltarune by Toby Fox and the other is from Omori by Omocat. Just wanted to list this here too just in case!
